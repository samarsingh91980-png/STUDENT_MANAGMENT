# Student Management System in C

## 📌 About the Project

The Student Management System is a simple C language project designed to manage basic student information.

The program allows the user to add, display, search, update, and delete student records.

## ✨ Features

- Add student details
- Display all students
- Search student by roll number
- Update student information
- Delete student record
- Simple menu-based interface

## 🛠️ Technologies Used

- C Programming Language
- Structures
- Arrays
- Loops
- Conditional Statements
- Functions and basic input/output

## ▶️ How to Run

1. Download or clone the repository.
2. Open `student_management.c` in a C compiler or VS Code.
3. Compile the program.
4. Run the executable.
5. Select an option from the menu.

## 🎯 Purpose

This project was created to practice basic C programming concepts and understand how a simple management system works.
